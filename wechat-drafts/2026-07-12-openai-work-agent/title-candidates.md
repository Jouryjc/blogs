# 标题候选（2026-07-12 OpenAI Work agent + GPT-5.6 + Codex 并入 ChatGPT）

## 1. 推荐标题（推荐流优先）

**每周 500 万人用 Codex，五分之一不写代码：OpenAI 干脆把它并进了 ChatGPT**

- 切入点：可观察行为（500 万周活、非开发者占比）+ 事件结论（并入 ChatGPT）。
- 数字有冲击力，非技术读者也能看懂"为什么要点开"。

## 2. 稳妥标题（老读者向）

**OpenAI 7/9 发布拆解：Codex 并入 ChatGPT 桌面端，Work agent 和 GPT-5.6 一起上线**

- 信息准确克制，三件事全部点到，适合已关注 OpenAI 动态的读者。

## 3. 大众标题（扩大入口）

**ChatGPT 开始替你干活了：写代码的 AI，正在接管报告、表格和 PPT**

- 去掉 Codex、GPT-5.6 等术语，用"报告、表格、PPT"落到普通职场读者的日常。

## 4. 专家标题（垂直人群）

**从委派三档控制到 rollout token 预算：Codex 三周更新暴露了 OpenAI 的 agent 工程路线**

- 保留关键工程名词，吸引做 agent 工程化的开发者。

## 5. 反差标题（判断感）

**OpenAI 这次发布的主角不是 GPT-5.6，而是"会自己干完活"的办公代理**

- 用"不是 A 而是 B"制造判断，指向文章核心论点：竞争从写代码转向干完活。

---

## 最终选择

**推荐标题（1）**：`每周 500 万人用 Codex，五分之一不写代码：OpenAI 干脆把它并进了 ChatGPT`

理由：以官方可核实数据开场，痛点（编码工具被非程序员大量使用的反差）+ 事件（并入 ChatGPT）都在前 18 字内出现；正文可完全兑现承诺。
