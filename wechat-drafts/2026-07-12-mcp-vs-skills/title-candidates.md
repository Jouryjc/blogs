1. **推荐**：都说 MCP 会被 Skills 淘汰，它的使用量为什么反而在涨？

2. **稳妥**：MCP 和 Skills 不是替代关系：一个是 Agent 的神经系统，一个是行动手册
   - 切入点：直接给判断，适合老读者，准确克制。
3. **大众向**：AI 圈吵了一周"谁淘汰谁"：给 Agent 装"手"还是装"脑"？
