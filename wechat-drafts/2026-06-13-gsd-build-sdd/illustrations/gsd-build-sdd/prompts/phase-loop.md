核心信息：
GSD 不让 Agent 在一条长对话里硬撑，而是把每个 phase 走成「讨论 -> 计划 -> 执行 -> 验收 -> 发 PR」。

版式：
- 横向流程图，五个大便签卡从左到右连接。
- 五个节点：
  1. 讨论：先定实现决策
  2. 计划：研究 + 拆任务
  3. 执行：fresh context 子代理
  4. 验收：检查需求和决策
  5. 发 PR：归档并交付
- 每个节点下只放一行短说明。
- 底部 takeaway：每一步都生成可读文件，下一步不靠聊天记忆。
