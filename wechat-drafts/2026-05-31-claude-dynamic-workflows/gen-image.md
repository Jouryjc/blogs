# Image Prompt: Claude Dynamic Workflows Sketchnote

这篇文章的所有封面和正文插图统一使用 Sketchnote / 蒸馏小余知识图解风格。

Visual direction:

- Deep Research Sketchnote, hand-drawn technical explainer infographic.
- Match the visual language of the reference WeChat article: https://mp.weixin.qq.com/s/GaEdNZRgPV4ofNXvJsJQjQ.
- Warm cream / off-white paper background as the main base, not a bright blue poster.
- Low-saturation pastel sticky-note blocks: pale blue, mint, soft yellow, soft pink.
- Deep navy hand-drawn outlines, slightly uneven but clean strokes, rounded card borders.
- Small corner doodles only: robot, checklist, workflow board, code file, gears, folders, arrows.
- Mobile WeChat readable: large Chinese labels, clear flow, compact knowledge-card density.
- Explain Claude Code Dynamic Workflows as an executable plan / workflow.js control plane.

Required feel:

- Friendly Chinese technical note.
- Like a hand-drawn engineering explainer saved from a research notebook.
- Must feel consistent with 蒸馏小余 / 码农小余知识图解.

Avoid:

- Corporate PPT.
- Generic flat vector flowchart.
- Photorealistic images.
- 3D glossy render.
- Cyberpunk or neon style.
- Dense tiny text, fake Chinese, random English filler.
- Big saturated blue/orange decorative background, excessive clouds/gears, empty poster-like spacing.
