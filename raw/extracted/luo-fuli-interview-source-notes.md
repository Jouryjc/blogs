## 核心观点整理

1. OpenClaw 被罗福莉视为 Agent 框架的分界点。它不是简单 UI，而是把长期上下文、任务编排、工具调用、记忆和人机交互组织成更厚的中间层，让模型能力被新的工作方式激发出来。
2. 大模型竞争正在从 Chat 范式转向 Agent 范式。过去主要靠预训练把模型能力做大，现在更关键的是模型、Agent 框架、环境、评估和 RL 后训练之间的协同。
3. Agent 范式很吃 Post-train。长上下文、多 Agent 协作、框架理解和任务环境都会进入训练闭环，导致后训练周期和算力投入被显著拉长。
4. 算力分配会变化。Chat 时代研究、预训练、后训练的用卡比例可能很偏预训练；Agent 时代，预训练和后训练接近 1:1 可能成为顶尖团队的新常态。
5. RL Infra 的中心从 Rollout 推理引擎转向 Agent 系统。它不仅要管模型推理，还要处理 Agent 框架、异构资源、CPU/GPU/存储调度、训练与推理不一致、任务中断等不确定性。
6. 1T 参数级基座模型是接近顶级 Agent 能力的入场券，但不是终点。下一阶段的胜负不只是参数量，还包括上下文、结构、后训练效率、推理成本和芯片适配。
7. MiMo-V2 的讨论强调了 MTP、Hybrid Attention、长上下文效率、数值稳定性、训练 spike、Expert 负载等工程与算法耦合问题。
8. Agent 会改写研究流程。过去一两个星期才能完成的 idea 验证、评估设计和代码实现，在 Agent 辅助下可能被压缩到小时级，并且可以通过多个子 Agent 并行交叉验证。
9. Multi Agent 的确定价值首先是效率和成本，不一定已经证明能直接抬高任务上限。真正的突破还要看框架、任务环境和后训练能否形成更强的闭环。
10. 端云混合会成为隐私和成本的重要解法。低难度、隐私相关任务尽量本地推理，高难度、高创造力、非隐私任务走云端。
11. 组织形态需要适配新范式。后训练需要多样性、敏捷性和对模糊性的容忍；预训练背景的人进入后训练是补充，不是错位。
12. 罗福莉强调环境比经验更重要。好奇心、热爱、基础能力、多样性和高标准环境，会比既有履历更影响人在新范式中的成长速度。
