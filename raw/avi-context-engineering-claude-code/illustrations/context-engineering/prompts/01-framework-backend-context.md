后端上下文工程三层结构 - Conceptual Framework

Create a polished editorial technical infographic in Chinese for a WeChat article.

Core idea:
- Claude Code 成本高，不一定是模型问题
- 真正关键的是后端有没有把上下文以 Agent 友好的方式提供出来
- Use a three-layer framework to explain this clearly

Layout:
- 16:9 horizontal infographic
- center title area at top: 后端上下文工程
- three large connected layers from left to right or top to bottom

Three layers:
1. Skills
   - 静态知识
   - 零轮询
   - 预置正确模式
2. CLI
   - 直接执行
   - JSON 输出
   - 清晰成功/失败信号
3. MCP
   - 实时状态
   - 后端元数据
   - 不要拿来塞整包文档

Add a bottom conclusion banner:
- 少探索
- 少重试
- 少 token 浪费

Visual style:
- modern editorial infographic
- clean cream background, slate blue, teal, coral accent
- flat vector, slightly hand-drawn feel, not photorealistic
- large readable Chinese text
- simple icons: book/knowledge for Skills, terminal for CLI, dashboard/state graph for MCP
- arrows should show that clearer context leads to lower token cost
- add a small token meter icon fading downward

Composition requirements:
- generous white space
- mobile-readable labels
- polished magazine quality

Aspect ratio: 16:9
