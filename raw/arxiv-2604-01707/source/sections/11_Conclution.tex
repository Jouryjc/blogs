\section{Conclusions}
\label{sec:conclusions}

In this paper, we provide an in-depth experimental evaluation and comparison of existing memory methods. We first present a unified modular framework that abstracts memory mechanisms into four core components—information extraction, memory management, memory storage, and information retrieval. Under this framework, we systematically evaluate representative memory methods on two benchmark datasets, and further conduct multi-dimensional experiments to study token cost efficiency, context scalability, evidence position sensitivity and LLM backbone dependence. Based on experimental results and analyses, we develop a new memory variant by combining existing techniques, which achieves strong accuracy while maintaining low overhead. Finally, we summarize the lessons learned and propose practical research opportunities that can facilitate future studies.
