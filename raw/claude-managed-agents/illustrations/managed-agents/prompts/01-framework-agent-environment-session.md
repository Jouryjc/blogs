# Claude Managed Agents 核心结构图

生成一张适合中文技术公众号的卡通手绘信息图。

## 目标

用最简单直观的方式解释 Claude Managed Agents 的四个核心概念：

- Agent：能力配置
- Environment：运行环境
- Session：一次具体执行
- Events：贯穿全过程的事件流

## 画面结构

- 横向 16:9 信息图
- 不要在画面中央放横幅标题，也不要生成装饰性产品名
- 左上区域：`Agent`
- 右上区域：`Environment`
- 下方区域：`Session`
- 外围环绕箭头或时间线：`Events`
- 用连线明确表达四者关系

## 每个模块必须包含的文字

### Agent 模块
- 标题：`Agent`
- 小标签：`模型`
- 小标签：`系统提示词`
- 小标签：`工具`
- 小标签：`技能`
- 小标签：`MCP`

### Environment 模块
- 标题：`Environment`
- 小标签：`沙箱`
- 小标签：`网络策略`
- 小标签：`依赖`
- 小标签：`挂载文件`

### Session 模块
- 标题：`Session`
- 小标签：`一次任务运行`
- 小标签：`状态`
- 小标签：`输出`

### Events 模块
- 标题：`Events`
- 小标签：`事件流`
- 小标签：`可回放`
- 小标签：`可恢复`

## 风格要求

- 手绘、卡通、非写实
- 明亮、友好、解释感强
- 像技术博主用来讲架构概念的插图
- 线条清晰，颜色偏浅蓝、浅黄、浅橙、浅绿
- 不要做成企业 PPT，不要做成深色科技海报
- 不要写英文长句，所有文字都用中文或简短英文标题
- 只允许出现这些大标签：`Agent`、`Environment`、`Session`、`Events`
- 不要额外生成其他标题文字

## 禁止事项

- 不要写实 3D
- 不要复杂透视
- 不要过度装饰
- 不要把文字做得太小
