# Claude Managed Agents 典型使用场景图

生成一张适合中文技术公众号的卡通手绘信息图。

## 目标

把 Claude Managed Agents 最典型的四类场景，用一张 2x2 网格图解释清楚。

## 画面结构

- 横向 16:9 信息图
- 主标题：`Claude Managed Agents 适合哪些任务`
- 下面是 2x2 四张卡片

## 四张卡片必须包含的标题和说明

### 左上
- 标题：`事件触发`
- 说明：`收到告警后自动修 Bug、开 PR`
- 图标建议：告警铃铛 + 扳手

### 右上
- 标题：`定时任务`
- 说明：`每天自动整理情报、报告和摘要`
- 图标建议：时钟 + 清单

### 左下
- 标题：`交办即执行`
- 说明：`人下达目标，Agent 自己跑完整个闭环`
- 图标建议：对话框 + 勾选结果

### 右下
- 标题：`长周期任务`
- 说明：`持续研究、迭代、回传阶段成果`
- 图标建议：长时间线 + 里程碑旗子

## 底部总结

底部加一行总结文字：

`越是长流程、异步、多工具的任务，越适合托管运行时`

## 风格要求

- 手绘、卡通、非写实
- 颜色明亮，留白充足
- 每张卡片都要一眼能分辨
- 字体清晰，适合手机阅读
- 看起来像会解释复杂概念的技术信息图

## 禁止事项

- 不要真实人物照片风格
- 不要赛博朋克
- 不要使用大段英文
- 不要把说明文字排得太密
