# 公众号封面图提示词

为一篇中文技术公众号文章生成封面图，画幅必须是 2.35:1。

## 核心要求

复用上一版封面的视觉语言和构图，只改主标题文字。

这张图必须看起来像：

- 明亮的浅蓝 + 暖黄 + 橙色卡通科技插画
- 画面四周有手绘电路线条、齿轮和微小装饰
- 中间是一块柔和的浅色大卡片，承载标题和主体插图
- 四角有可爱的卡通小云朵
- 下方中间是一排技术概念图标：大脑 -> 工具箱 -> 透明沙箱盒子 -> 事件流圆环
- 图标之间用箭头连接
- 整体像“技术博主画的手绘科普封面”，不要像重新设计的另一张海报

## 标题文字

主标题：`claude managed agents`

副标题：`Agent 基础设施开始产品化`

## 构图要求

- 主标题放在中央大卡片上半部分
- 主标题必须大、醒目、可读
- 主标题必须严格使用小写英文：`claude managed agents`
- 不要把主标题翻译成中文
- 副标题放在主标题下方，保持和上一版类似的黄色笔刷底或高亮条效果
- 中央卡片下半部分放一排四个图标：
  - 一个发光的卡通大脑
  - 一个打开的工具箱
  - 一个透明的沙箱立方体，带锁
  - 一个循环播放感的事件流圆环
- 图标之间用橙色箭头连接
- 最下方可以保留一行小的流程说明文字：
  `配置 (Config) -> 环境 (Env) -> 执行 (Exec) -> 回放 (Replay)`

## 风格要求

- 手绘卡通
- 非写实
- 明亮友好
- 配色以浅蓝、暖黄、橙色为主
- 保持上一版那种“边缘有科技涂鸦，中间有大白色信息卡片”的感觉
- 像技术科普插画，不像商业海报

## 文字要求

- 所有文字必须清晰可读
- 只保留主标题、副标题和底部流程说明，不要新增别的小字

## 禁止事项

- 不要深色背景科技海报
- 不要写实人物
- 不要 3D 金属质感
- 不要改成另一种完全不同的版式
