# 只需10步HERMES配上NVIDIA免费Minimax-m2.7大模型

NVIDIA NIM是NIVIDA推出的 AI 推理微服务平台，用于快速部署和调用各种大模型最近上线了一批新的免费大模型

我亲自跑了一遍流程并配置到Hermes上面，这波免费羊毛挺香的，废话不多说进入主题

[1⃣](https://t.co/0AX7vZAq8Q)直接打开 [build.nvidia.com](https://t.co/MEw7W9SMKi)

2⃣使用邮箱注册账号，然后用手机号收取验证码，国内手机号可以收到

3⃣ 登录成功后点击网页右上角进入账号，点击 Generate API Key

4⃣ 输入Key Name，点击 Generate Key，可以看到有效期12个月

![](imgs/img-001-HGMdC4pbgAEeRDq.jpg)

5⃣ 复制 key，注意key只会出现一次

6⃣  进入 Hermes setup  Model & Provider

![](imgs/img-002-HGMfYa6asAAVFU.jpg)

7⃣ 选择  Nvidia NIM

![](imgs/img-003-HGMhGmDaUAAUkH9.png)

[8⃣](https://t.co/MEw7W9SMKi)NVIDIA NIM API key: 刚才复制API key
      Base URL: https://integrate.api.nvidia.com/v1/chat/completions

9⃣ 选择大模型: minimaxai/minimax-m2.7

![](imgs/img-004-HGMefwUakAAY59u.jpg)

🔟 最后测试一下

![](imgs/img-005-HGMd5IFaMAAvVbC.jpg)

写在最后:

Nvidia限制每分钟40次请求，个人日常使用来说应该绰绰有余

就算业务量稍微大一点只要合理分配使用速率就可以了

毕竟0撸大厂基础设施的大模型，已经很香了
