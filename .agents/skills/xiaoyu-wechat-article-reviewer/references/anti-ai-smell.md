# 蒸馏小余去 AI 味规则

## 高风险句式

优先扫描并改掉这些痕迹：

- `换句话说`
- `这意味着`
- `这一步让`
- `真正 / 核心 / 本质 / 价值就在这里`
- `值得注意的是`
- `总的来说`
- `不仅如此`
- `很多人会以为`
- `这件事说明`
- `可以看到`
- `从 X 到 Y`

这些词不是绝对禁用，但连续出现时会让文章像总结器输出。

## 诊断方法

定位 AI 味时，不要只说“口吻不自然”。必须指出：

1. 具体位置：标题、第一屏、某个小节、结尾。
2. 具体句式：哪句话像模板。
3. 读者感受：为什么像整理材料而不是人在判断。
4. 改法：换成场景、动作、边界、反例或作者取舍。

## 改写方法

### 第一屏

弱写法：

> Agent 总学不会，常常不是模型不够聪明，而是反馈没有进入执行规则。

强写法：

> 你纠正过 Agent 一次，它当场认错。两天后，同类 issue 进来，它又按旧规则贴错标签。

原则：先给读者见过的动作，再给结论。

### 段落推进

弱写法：

> 这一步让自我改进从玄学变成普通软件工程。

强写法：

> 我愿意让 Agent 提 PR，但不会让它直接改 main。

原则：少写价值升华，多写作者会怎么做。

### 结尾

弱写法：

> 希望这篇文章能帮你少走弯路。

强写法：

> 下次 Agent 又犯同一个错时，先看三件事：错误有没有被记录，纠正有没有变成 lesson，lesson 有没有进 PR。

原则：把结尾变成动作，不变成祝福。

## 保留边界

去 AI 味不是把文章改得随意。

- 不改事实。
- 不虚构测试、数据、引用或官方说法。
- 不把谨慎判断写成绝对结论。
- 不为了“人味”加无关故事。
- 不把技术名词全删掉；要解释它的工作流后果。
