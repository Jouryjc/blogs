# Image style for 蒸馏小余

Use this visual direction exactly:

- hand-drawn technical explainer infographic
- sketchnote style
- warm cream paper background
- black hand-drawn lines
- pastel rounded boxes
- clear arrows
- cute engineer doodles
- formula blocks
- takeaway summary

Composition rules:

- Chinese text must be large, short, and readable on a mobile screen.
- Use a clean information hierarchy, not a dense poster.
- Draw simple doodles of a phone, a laptop/Mac host, a devbox/SSH server, approvals, terminal output, diffs, and test results.
- Do not use photorealism, 3D rendering, glossy gradients, corporate stock art, cyberpunk neon, or real product logos.
- Do not copy any existing reference image layout.
- Keep all important title text and the main workflow inside the centered safe crop area.
- Use warm cream as the main background, black/dark ink outlines, and soft pastel blue/yellow/green/orange fills.
