# 标题候选

1. **模型切换别再重算长上下文：KV Cache 开始跨模型接力**（推荐；动作提醒 + 方法替换）
2. **跨模型 KV 共享：一次 Prefill，能否让多个模型接力？**（稳妥；研究问题 + 边界）
3. **Agent 一换模型就重读上下文，这篇论文想省掉这次等待**（大众；现场痛点 + 直接收益）
4. **从 899ms 到 138ms：跨模型 KV Handoff 的收益与边界**（专家；结果前置 + 限定）
5. **多模型推理最浪费的，不是 Decode，而是重复 Prefill**（反差；不是 A，而是 B）

五个候选覆盖提醒句、问句、场景句、结果句和对比判断五种结构，只有一个问句。

最终采用第 1 个。它先点出多模型 Agent 能感知的重复等待，再把跨模型 KV sharing 作为解释路径；第一屏必须同时给出“源 KV 已存在”和“仍需质量 fallback”两个边界，避免把论文写成无条件加速。
