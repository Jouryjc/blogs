# 图片提示词：文章封面

生成 1 张微信公众号文章封面，比例 2.35:1，横版，适合 1080x458。

主题：Claude Code workflow 和 goal 怎么选。

画面文案必须是中文，且保持短句：

- 主标题：workflow vs goal
- 副标题：一个管编排，一个管收工
- 标签：Claude Code / Agent 长任务

视觉风格：

- 蒸馏小余知识卡 / Deep Research Sketchnote 技术图解风格。
- 暖奶油纸底，深海军蓝手绘描边，低饱和 pastel 色块。
- 中间保留 1:1 安全裁剪区，主标题、副标题、两个核心图标都放在中央区域。
- 左侧画一个“workflow”：多个小 agent 卡片被一段 JS 脚本连接，表现后台并行编排。
- 右侧画一个“goal”：一个目标旗帜、测试通过勾号、循环箭头，表现持续工作到验收。
- 两侧用一条清晰分割线或天平结构对比，但不要做企业 PPT 风。
- 不要真实 Claude / Anthropic logo，不要英文长句，不要 3D，不要赛博霓虹。

输出要求：

- 生成 PNG。
- 文字清晰，适合手机端阅读。
- 所有关键元素留在中央安全区，不要贴边。
