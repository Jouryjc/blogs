# 图片提示词：选型表

生成 1 张 16:9 横版中文知识卡，PNG。

先参考同目录中这两张已有配图的视觉语言：

- `./01-mechanism-map.png`
- `./03-goal-example.png`

目标是和这两张保持同一套图卡风格，而不是生成干净 PPT / 几何 UI 图。

标题：怎么选：先看任务痛点

做成四格决策表：
1. 一句话能完成 -> prompt
2. 多分片并行 -> workflow
3. 单线多轮验收 -> goal
4. 高风险决策 -> plan + 人类确认

旁边小对比：
workflow = 编排脚本
goal = 完成合同

底部结论：规模问题用 workflow，收工问题用 goal。

风格要求必须贴近参考图：

- 暖奶油纸底，有轻微纸张纹理。
- 深海军蓝手绘粗线条，边框略微不规则，有 sketchnote 手绘感。
- 标题用手写粗体感，而不是规整系统字体。
- 四个决策卡片像贴纸 / 便签，低饱和蓝、绿、黄、粉，带胶带或小圆点装饰。
- 箭头、图标、卡片边框都要手绘，不要机械直线。
- 可以使用脚本、分支箭头、目标旗帜、测试勾号、人工确认图标。
- 中文清晰，文字不要太密。
- 不要 logo，不要 3D，不要赛博霓虹，不要企业 PPT 风。

输出文件名：`04-decision-matrix.png`。如果该文件已存在，请覆盖它。
