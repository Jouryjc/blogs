# 图片提示词：goal 用法图

生成 1 张 16:9 横版中文知识卡，PNG。

标题：goal：把停止条件写成合同

左侧输入卡片：
`/goal pytest tests/auth -q exits 0`
标签：证据、边界、停止规则

中间画循环：Claude 执行一轮 -> 展示测试结果 -> evaluator 判断 -> no 继续 -> yes 停止。

右侧警示：评估器不调用工具，只看 transcript。

底部结论：目标要可裁决，不要写愿望。

风格：暖奶油纸底，深海军蓝手绘线，低饱和便签色块，循环箭头、勾号、停止牌，蒸馏小余 sketchnote 技术图解。中文清晰，不要 logo，不要 3D。
