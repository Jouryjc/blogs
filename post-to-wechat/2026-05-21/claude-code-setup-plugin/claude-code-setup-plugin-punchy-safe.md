这个插件最有用的地方很直接：

**先让 Claude 读项目，再告诉你当前仓库最该配什么。**

它会只读分析项目结构、依赖和代码模式，然后推荐适合你的自动化配置。

怎么用：

1. 在插件页安装 claude-code-setup。
2. 回到项目里，让它推荐当前仓库的自动化配置。
3. 不要全装，先挑最痛的 1-2 个落地。

它会重点看 5 类：工具连接、流程沉淀、自动检查、专项助手、快捷命令。

小余判断：这比凭感觉堆配置靠谱。新项目接手、老项目补工程化、团队统一工作流，都可以先跑一遍。
