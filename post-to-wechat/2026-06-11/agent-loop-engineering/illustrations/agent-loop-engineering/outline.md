# Agent Loop Engineering 配图规划

## 视觉风格

- 蒸馏小余知识卡 / Deep Research Sketchnote
- 暖奶油纸底
- 深海军蓝手绘描边
- 低饱和便签卡片
- 中文标签简短可读
- 不使用真实品牌 Logo

## 图片清单

1. `article-cover.png`
   - 用途: 封面和正文第一张图
   - 主题: Agent 从 Prompt 到 Loop，跑到验收
   - 版式: 中央 1:1 安全区里放标题和闭环流程，左右两侧做旧方式/新方式对比

2. `prompt-vs-loop.png`
   - 用途: 解释 Prompting 和 Looping 的区别
   - 主题: 一条提示词给输出，一个循环给可验收结果
   - 版式: 左右对比图

3. `closed-loop-gates.png`
   - 用途: 解释 closed loop 的五个闸门
   - 主题: 目标、上下文、动作、反馈、停止条件
   - 版式: 多阶段流水线

4. `loop-building-blocks.png`
   - 用途: 解释工程积木
   - 主题: automations、worktrees、skills、MCP、subagents、memory
   - 版式: 分层能力栈
