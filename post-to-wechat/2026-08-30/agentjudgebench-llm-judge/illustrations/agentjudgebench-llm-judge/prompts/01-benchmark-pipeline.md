# 01 基准流水线图片提示

生成 1 张 16:9 横版中文技术知识卡，建议 1672×941。

主题：这篇论文不是测 Agent，而是测给 Agent 打分的裁判。

严格沿用同目录上两级 `gen-image.md` 的蒸馏小余知识卡视觉：暖奶油纸底、深海军蓝手绘线、低饱和便签卡、清楚箭头、手机端可读。原创重绘，不复制论文原图。

构图：横向五段流水线，模块从左到右：

1. `3,808 条基础记录`，图标为问题卡和工具 Schema
2. `三档改写`，三个短标签：`Easy`、`Medium`、`Hard`
3. `5 个 Generator`，图标为 Agent 生成工具调用 DAG
4. 分成上下两个裁判卡：`程序评分器`、`6 个 LLM Judge`
5. 四枚结果标签：`选工具`、`参数结构`、`调用顺序`、`需求覆盖`

标题必须准确写成：`这篇论文不是测 Agent，而是测裁判`

在裁判卡与四项结果之间写一个短标签：`Alignment`

底部 takeaway 必须准确写成：`程序评分器是可复现参考，不是绝对真理`

不要添加其他长句，不要真实品牌 Logo，不要乱码英文。
