# 标题候选

1. **给 Agent 判卷，AI 裁判先撞上了结构性天花板**（推荐；结果前置 + 工程判断）
2. **LLM Judge 也要先考试：AgentJudgeBench 的四条评测警告**（对象 + 清单交付）
3. **六个 AI 裁判都说对，不代表它们真的判对了**（具体行为 + 认知反差）
4. **无 GT 的 Agent 评测，Judge 为什么会集体收敛？**（现场问题 + 解释路径）
5. **Agent 评测的最大盲区，不是被测模型，而是裁判**（不是 A，而是 B）

五个候选覆盖结果句、清单句、反常识判断、问句和对比句五种结构，只有一个“为什么”标题。

最终采用第 1 个。它先给出 Agent 评测的工程后果，再把 AgentJudgeBench 作为证据路径；正文第一屏会立即解释“天花板”指 Judge 与程序评分器的 alignment 收缩，不把它误写成真实任务准确率。
