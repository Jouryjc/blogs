# 正文图 2：Semantic Cache 错误命中

生成 1 张 16:9 横版中文技术失败流程图，蒸馏小余知识卡 / Deep Research Sketchnote 风格。

主题：Semantic Cache 可能在正常返回 200 OK 的同时复用错误旧答案。

核心信息：向量相似只代表“看起来像”，不代表两个业务问题可以共用答案；错误命中会绕过模型。

版式：

- 暖奶油纸底，顶部居中标题：`最危险的 Cache：命中了，答案却错了`
- 从左到右画清楚失败路径：
  1. 浅蓝便签：`新问题` / `年付套餐能退款吗？`
  2. 浅黄缓存便签：`缓存旧问题` / `月付套餐能退款吗？`
  3. 两张便签之间用珊瑚色差异标签：`年付 ≠ 月付`
  4. 中间向量点阵判断门：`相似度达标` → `语义命中`
  5. 主箭头绕过灰色友好机器人，机器人旁标 `模型未调用`
  6. 右侧绿色状态标签 `200 OK`，下方淡粉答案卡：`返回月付规则` / `答非所问`
- 底部三张安全便签：`关键实体入 Key`、`时效设置 TTL`、`高风险问题绕过`
- 底部结论条：`语义相似，不等于业务等价`
