# Shared Image System Prompt

Create Chinese technical sketchnote infographics in 蒸馏小余知识卡 / Deep Research Sketchnote style.

Core style:
- Warm cream paper background, not bright blue/orange poster.
- Dark navy hand-drawn outlines, rounded sticky-note panels, marker arrows.
- Low-saturation pastel blocks: pale blue, mint green, soft yellow, soft pink, light peach.
- Clear engineering flowchart layout, mobile-readable Chinese labels.
- Compact knowledge-card density with clean spacing.
- Small friendly engineer or robot doodles only when useful.
- Use short Chinese labels, no fake long text, no real brand logos.

Avoid:
- Photorealistic image.
- 3D glossy render.
- Corporate PPT.
- Dark cyberpunk.
- Dense tiny text.
- Random English filler.
- Watermark, signature, public account name.
