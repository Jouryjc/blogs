Article facts to preserve carefully

- The source argues that many RAG failures start upstream of retrieval, because fixed-size chunks are weak knowledge units.
- The alternative unit is an IdeaBlock: a question, a trusted answer, and governance fields such as source, version, clearance, tags, entities, and keywords.
- Source claims include 40x corpus size reduction, about 3x fewer tokens per query, and about 2.3x better vector-search relevance.
- The X Article cites an internal Blockify benchmark across 17 documents and 298 pages: average cosine distance was 0.1585 for IdeaBlocks and 0.3624 for naive chunks.
- The same source says 2,042 raw IdeaBlocks collapsed to 1,200 canonical IdeaBlocks; word count dropped from 88,877 to 44,537; distilled data outperformed undistilled data by 13.55% on vector accuracy.
- The README claims 78x aggregate performance, 2.29x vector search accuracy, 29.93x distillation, 3.09x token efficiency, and 40x size reduction. Treat these as project/source claims, not independently verified industry facts.
- Supported ecosystem claims from README include ChromaDB, Pinecone, Cloudflare Vectorize, Neo4j, SQLite, PostgreSQL, Redis, filesystem, Docker, Helm, FastAPI service, and Claude Code skill.
