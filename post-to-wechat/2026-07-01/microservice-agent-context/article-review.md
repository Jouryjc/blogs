## 具体 AI 味位置

1. 第一屏：`这个方向没错，但还不够。`
   - 问题：像通用总结句，缺少开发者现场。
   - 改法：改成跨订单、库存、支付的 user story 场景，先让读者看到故障后果。

2. 第一屏：`所以问题不是...而是...`
   - 问题：典型转述腔，像把原文观点重新排版。
   - 改法：改成“把所有仓库放进 workspace 有用，但只能解决看得到代码”，再列三件事。

3. 中段：`它拥有哪些核心实体和业务词？`
   - 问题：`核心` 被指标命中，虽然语义正常，但可用更具体词替换。
   - 改法：改为 `主要实体和业务词`。

4. 验证小节：`更实用的做法，是把验证拆到协议层。`
   - 问题：像客观总结，作者判断不够强。
   - 改法：改为 `我更愿意把验证拆到协议层。`

5. 结尾：`这套闭环会逼着文档保持克制，也会逼着 Agent 在局部证据里前进。`
   - 问题：略抽象。
   - 改法：改为 `逼着 Agent 拿局部证据说话`。

## 优先修改

1. 第一屏从抽象问答改成开发场景。
2. 删除或替换模板过渡词：`这个方向`、`所以问题`、`更实用的做法`、`核心`。
3. 把作者判断提前并具体化：我会怎么拆文档、怎么做验证、先做哪条 user story。
