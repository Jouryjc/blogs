# 内容分析

## 核心钩子

Codex 远程操作的重点不是“手机写代码”，而是“手机接管 agent 的关键决策点”。这句话适合放在图的主视觉区域，能快速纠正误解。

## 事实要点

1. ChatGPT 手机 App 现在可以在预览版中使用 Codex。
2. 手机端可以开始新任务、查看输出、改方向、批准下一步。
3. Codex 继续运行在宿主机或远程环境里。
4. 文件、凭证、权限和本地配置留在宿主机。
5. Remote SSH 已经 generally available。
6. iOS / Android 在支持地区推出预览；Windows 宿主机连接支持是 coming soon。

## 视觉机会

- 用三段流程表达：手机端 -> Codex 宿主机 -> Devbox / SSH。
- 用“公式块”强化判断：远程操作 = 线程状态 + 人类判断 + 宿主机执行。
- 用四个小卡片表达使用场景和边界。
- Notion 风格适合用干净留白、手绘线框、轻量 doodle、浅色圆角块承载信息。
