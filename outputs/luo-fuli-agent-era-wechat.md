# 罗福莉这场 3.5 小时访谈，真正说透了 Agent 时代的换挡

先说结论：这场访谈最重要的不是“罗福莉怎么看 OpenClaw”，也不是“小米的 MiMo-V2 做了什么技术细节”，而是她把大模型行业正在发生的一次换挡讲清楚了。

过去两三年，大家讨论大模型，核心问题基本是：谁的预训练数据更好，谁的参数规模更大，谁的推理能力更强。到了 2026 年，这个问题开始变成：模型能不能在 Agent 框架里完成长程任务，能不能通过后训练理解环境、工具、记忆和协作，能不能自己参与下一轮模型和系统的改进。

这意味着竞争中心正在从“训出一个更强的 Chatbot”，转向“搭出一个能持续进化的 Agent 系统”。

## 一、OpenClaw 的意义，不是又多了一个 AI 工具

很多人第一次看到 OpenClaw，会把它理解成 Claude Code 加一个更好用的交互界面。这个理解没有错，但只说到表层。

罗福莉真正强调的是：Agent 框架正在成为模型和任务之间的厚中间层。这个中间层里有长期上下文、工具调用、任务拆解、记忆、评估、多人协作，甚至还有一部分“怎么跟人一起工作”的产品定义。

为什么这件事重要？

因为 Chatbot 时代，模型拿到的上下文通常很短。用户问一句，模型答一句，能力主要靠预训练里压进去的知识和推理模式。但 Agent 时代，模型面对的是一个持续展开的环境：它可以读文件、写代码、调用工具、保存记忆、反复修正、接收反馈。上下文变长以后，模型不是在回答一个问题，而是在参与一个过程。

这就是范式变化的第一层：智能不只来自模型本体，也来自模型被放进了怎样的工作系统。

## 二、Agent 时代，后训练不再是“最后调一下”

过去很多人理解后训练，会把它当成模型出厂前的精修：对齐一下、强化一下、让回答更好看一点。

但在 Agent 范式里，后训练的角色变了。它要让模型理解框架、理解工具、理解长上下文，甚至理解多个 Agent 之间怎么协作。换句话说，后训练不只是让模型“答得更好”，而是让模型“在系统里工作得更好”。

这也是为什么罗福莉判断，Agent 范式会显著拉长 Post-train 周期，后训练的算力投入可能接近预训练。以前预训练是主菜，后训练像配菜；现在顶尖团队可能会进入预训练和后训练接近 1:1 的资源结构。

这背后有一个很务实的原因：Agent 的变化太快。你今天假设 128K 上下文够用，几个月后可能就发现任务环境要求远远超过这个量级；你今天为某个推理卡、某个工具链设计结构，半年后可能场景已经变了。所以模型结构不能只为静态指标优化，还要为后续的 Agent 适配留下空间。

## 三、RL Infra 的中心，从推理引擎变成 Agent 系统

这场访谈里一个很关键、但容易被忽略的点，是 Infra。

在 Code、Math 这类 Chat Reasoning 场景里，RL Infra 的核心更像是推理引擎：模型长时间思考，Rollout 出答案，然后根据结果训练。但 Agent 场景不是这样。任务跑到一半可能超时，工具可能失败，环境可能变了，训练和推理可能不在同一套资源上，CPU、GPU、存储都要一起调度。

所以系统中心变了：过去是围绕模型推理，现在是围绕 Agent 行为。

这对团队的要求会高很多。做预训练 Infra，追求的是确定性、稳定性、少出 spike；做 Agent RL Infra，需要能容忍模糊性和中断，还要能把算法、工程、资源调度放进同一个实验闭环。一个团队如果只有大模型训练经验，但没有快速改框架、改环境、改评估的能力，会很难跟上这一轮节奏。

## 四、1T 是入场券，但不是终点

访谈里提到 1T 参数级模型，容易被理解成“参数越大越好”。但罗福莉讲得更细：1T 更像是接近顶级 Agent 能力的一张入场券。

入场券的意思是，没有这个级别的基座模型，很多复杂任务的上限很难够到。但真正决定胜负的，不只是参数量，还包括架构是否高效、长上下文是否便宜、后训练能不能吃到 Agent 的红利、推理成本能不能支撑真实场景。

MiMo-V2 的讨论放在这里看，就不是单个模型发布，而是一组工程取舍：MTP 用来提高推理效率，Hybrid Attention 用来平衡长上下文成本，训练更大模型时要解决数值稳定性、loss spike、Expert 负载不均等问题。这些细节说明，大模型竞争已经不是“多买卡多堆参数”那么简单，而是算法、Infra、芯片、成本和场景一起决策。

真正的问题变成：下一阶段到底应该 scale 什么？是参数量，是上下文，是 Agent 环境，还是后训练数据和评估系统？

## 五、Agent 会先改写研究工作本身

这场访谈最有冲击力的部分，是罗福莉谈到研究流程被 Agent 压缩。

以前一个研究想法，从写代码、设计评估、跑实验到看结果，可能要一两周。现在有 Agent 辅助后，部分流程可以压缩到小时级，而且多个想法可以并行给不同子 Agent 验证，再交叉检查。

这对 AI Lab 的含义很直接：研究效率会变成核心竞争力。

如果一个研究者 taste 很准，过去可能受限于实现速度；现在实现速度突然被放大，关键就变成谁能提出更好的问题、设计更好的评估、识别更有价值的失败样本。Agent 不只是帮研究员省时间，它会把研究员的判断力放大。

这也解释了为什么罗福莉会说，一些过去看起来很有创造力、很难被流程化的工作，现在也可能被 Skill 化、Workflow 化。这里不是简单的“AI 替代人”，而是人的经验正在被拆成可执行流程，再反过来训练更强的模型和系统。

## 六、组织也要跟着变

技术范式变了，组织不可能不变。

罗福莉反复强调多样性、热爱、好奇心、环境，而不是只强调履历和职级。这个判断和 Agent 时代是匹配的：后训练和 Agent 研究有大量模糊地带，需要有人频繁使用模型、测试边界、积累私有评测、快速把体验转成数据和训练环境。

预训练背景的人进入后训练，也不是“跨错方向”，反而可能带来很重要的补充。因为 Agent 后训练不是纯产品调参，它会反过来影响下一代模型结构、数据和 Infra 判断。懂底层训练的人，如果同时理解 Agent 使用体验，就更容易把后训练里的发现带回预训练决策。

所以组织的关键词不是层级更复杂，而是反馈更短、信息更流动、试错更快。一个好环境，要能让人把自己的长处暴露出来，也能让别人快速吸收这些长处。

## 七、普通团队现在应该改什么

如果把这场访谈落到行动上，我觉得有五件事值得立刻做。

第一，不要只评测模型回答，要评测任务闭环。Agent 时代的能力，不是单轮问答分数，而是长程任务完成率、失败恢复能力、工具使用质量和成本。

第二，把后训练、评估、Agent 框架放到同一个系统里看。单独优化 prompt、单独换模型、单独改工具，都只能解决局部问题。真正的提升来自闭环。

第三，重新分配算力和工程资源。如果还把大部分资源压在预训练，而后训练、评估、环境构造只是附属，很可能会错过 Agent 范式的关键增量。

第四，让团队成员高频使用最前沿的 Agent 工具。不是为了追热点，而是为了建立边界感。只有真的用过、失败过、对比过，才知道模型到底缺什么。

第五，提前考虑端云混合。隐私任务、低难度任务、本地数据相关任务，长期看更适合本地推理；高难度、高创造力、非隐私任务走云端。这不是产品包装，而是成本和信任的基础架构问题。

## 结尾：这轮变化，不只是模型变强了

罗福莉这场访谈真正有价值的地方，是她没有把 AI 进步讲成单一模型能力曲线，而是讲成一个系统性变化：模型、Agent 框架、后训练、Infra、算力、组织和人，都在一起移动。

ChatGPT 让大家第一次感受到大模型的智能。R1 让大家看到推理和强化学习的力量。到 2026 年，Agent 正在把智能从“回答问题”推向“完成任务”，也把竞争从“谁的模型更强”推向“谁的系统能更快进化”。

这对开发者、创业者和 AI 团队都是同一个提醒：不要只盯着模型榜单。下一轮差距，很可能出现在那些不容易被榜单捕捉的地方：长上下文、工作流、评估体系、后训练效率、工具环境、组织敏捷性，以及人和 Agent 一起迭代的速度。

如果只用一句话总结这场访谈：

Agent 时代的核心竞争力，不是拥有一个更会聊天的模型，而是拥有一个能不断把任务、经验和反馈转化为新能力的系统。
